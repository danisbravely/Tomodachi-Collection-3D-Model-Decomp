# Tomodachi-Collection-3D-Model-Decomp
A collection of 3D Model source files from Tomodachi Collection for the DS

I do not own any of these models, all credit goes to Nintendo and their respective creators, and the developers of Tomodachi Collection

Not really a "Decomp", I just didn't know what else to call it.

This does not include the Mii Character's Head, Hair, Facial Features, or Accessories (Glasses, Beards, Mustaches, Moles) modesl. I don't know where or how to find them, they're probably stored differently than the other models. (Their default "Mii Maker" outfits are included among the rest, though.)

^This dump is the result of my research toward Tomodachi Collection's Mii character models, so if you know anything about these, please let me know.

Dumped using Apicula.

Note: 
      nitro.rar is the raw extracted 3d model files from the game, of various file types. These files are viewable through Apicula using the view command, but cannot be ported to software like blender for viewing. You will          need to convert them to .dae files, which Apicula can also do.

      
      File Sizes: 
      
                  Raw nitro: About 100 Megabytes (After extraction from the .rar, download will be about 39mb.)
                  Converted .dae files: About 43 Gigabytes (Make sure you have the space for these!)


Because of the immense file size, I cannot upload the converted .dae files to Github because even as a compressed .rar file, it exceeds Git LFS's 2 Gigabyte limit for free users. In fact, it was even difficult to get the raw nitro files on here. I might soon find a way to upload them outside a .rar, because they should fit through Git LFS.
